# Gestionnaire de Comptes Utilisateurs

Une application ASP.NET Core pour gérer les comptes utilisateurs.

---

## Description
Ce projet a pour but de fournir une plateforme de gestion des utilisateurs avec les fonctionnalités suivantes :
- Inscription et connexion sécurisées.
- Gestion des profils utilisateurs.
- Tableau de bord avec statistiques et suivi des activités.
- API RESTful pour l’intégration avec des services externes.

---

## Prérequis
Avant de commencer, assurez-vous d'avoir installé :
- **Visual Studio 2022** ou version plus récente.
- **.NET 8 SDK** ou version supérieure.
- **SQL Server** (LocalDB ou standard).

---

## Installation

### 1. **Cloner le dépôt**
Clonez ce dépôt en local avec la commande suivante :
```bash
git clone https://github.com/username/gestionnaire-comptes.git
```

### 2. **Ouvrir le projet**
1. Ouvrez Visual Studio.
2. Cliquez sur **Fichier > Ouvrir > Projet/Solution**.
3. Sélectionnez le fichier `GestionnaireComptes.sln` situé dans le dossier cloné.
